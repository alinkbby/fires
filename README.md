# Огоньки сна

Огоньки-серии для режима сна, как в TikTok: «Проснулась вовремя», «Легла спать вовремя» и свои огоньки.

- Огонёк растёт с каждым днём подряд и гаснет, если пропустить день.
- Отметить можно только до своего времени.
- Восстановить огонёк можно в течение 3 дней, 5 восстановлений в месяц на каждый огонёк.
- Прошлые дни можно внести в календаре.

Отметки хранятся на телефоне. В приложении есть резервная копия: её можно скопировать в Заметки и потом вставить обратно.

Как поставить на iPhone: открыть сайт в Safari → «•••» → «Поделиться» → «На экран „Домой“».
